# Ironfront 1936 デモ

HOI4風のUIと簡易ゲームループを再現した静的デモです。

## 実行方法

### 1) ローカルサーバーで起動（推奨）

```bash
python -m http.server 8000
```

ブラウザで `http://127.0.0.1:8000` を開いてください。

### 2) HTMLを直接開く（簡易）

`index.html` をブラウザで開くだけでも表示できます。

## 操作

- **国家方針**: ボタンで方針を選択。進行中は中止可能。
- **NF(国家方針)ツリー**: 前提条件を満たした方針のみ解禁。完了で次が開く。
- **日付を進める**: 週次で資源が変化し、方針の進行が進みます。
- **政策決定**: 政治力を消費して即時効果を得ます。
- **作戦命令**: 戦況ログに行動が追加されます。
- **師団移動**: 師団を選択して戦況マップをクリック。

## ざっくりプレイ手順

1. NF(国家方針)ツリーから解禁済みの方針を選択。
2. 「日付を進める」で週次進行し、NF完了を目指す。
3. 師団を選択してマップをクリックし、前線を動かす。
4. 政策決定や作戦命令を挟んで戦況ログを確認。
